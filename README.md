# SmartHomeMonitoring

Android smart home monitoring app with Firebase sync.

## Home Simulator

A web-based **physical home view** lets you demo the app live: toggle a light on your phone and see it change on screen.

```powershell
cd home-simulator
npx --yes serve .
```

Open `http://localhost:3000`, log in with the same account as the mobile app, then control devices from the phone. See [home-simulator/README.md](home-simulator/README.md) for full setup.
